# 🎬 Wovie
<img width="819" height="751" alt="Wovie film page" src="https://github.com/user-attachments/assets/1af7a765-0a20-4eeb-8d6f-63c3ca4748cf" />

Find a film, keep a watchlist: a film catalogue on top of TMDB with real scores, your own ratings, favourites and
lists. Built with Next.js 16, React 19, TypeScript, Prisma and PostgreSQL.

> Rewrite of [Wovie v1](https://github.com/TheRainHub/Wovie), a plain HTML/CSS/JS version from the ZWA course.

The app lives in [`wovie-v2/`](wovie-v2/). Setup, scripts and how scores are worked out are in
[wovie-v2/README.md](wovie-v2/README.md).

Live demo: [wovienext.vercel.app](https://wovienext.vercel.app)
